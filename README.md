# Proyecto: Dosificador de Comida para Pollos 🐔🌾

¡Bienvenido al repositorio del **Dosificador de Comida para Pollos**! Este proyecto es un sistema automatizado diseñado para facilitar y controlar la alimentación de aves de corral de manera eficiente.

## 📝 Descripción del Proyecto

Este sistema automatiza la tarea de dosificar alimento para pollos utilizando una tolva y mecanismos de control programables. El proyecto integra diseño mecánico impreso en 3D, placas de circuito impreso (PCB) a medida y lógica de control industrial a través de OpenPLC, enlazado con hardware Arduino.

## ✨ Características Principales
- **Automatización**: Control de la dosificación mediante PLC.
- **Diseño a Medida**: Modelos 3D de las piezas mecánicas (tolva, dosificador).
- **Control Integrado**: PCB personalizada y lógica de OpenPLC con Arduino.

## 🛠️ Tecnologías y Hardware Utilizado
- **Software**: OpenPLC, Entorno Arduino, Software de modelado 3D (para las piezas impresas).
- **Hardware**: Placa Arduino, Componentes electrónicos, Piezas impresas en 3D.
- **Circuitos**: PCB diseñada específicamente para el control del sistema.

## 📁 Estructura del Repositorio

La organización del proyecto es la siguiente:

- `assets/`: Recursos multimedia, incluyendo el video de demostración.
- `docs/Reporte/`: Documentación y reportes del proyecto.
- `hardware/3D_Models/`: Modelos para impresión 3D de los componentes del dosificador.
- `hardware/PCB_Design/`: Archivos de diseño de la placa de circuito impreso.
- `software/Arduino_OpenPLC/`: Código fuente de Arduino y lógica de OpenPLC.
- `software/Simulation/`: Archivos de simulación de OpenPLC.
